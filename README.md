# MedReg Navigator

Демо для портфоліо: користувач описує медичне ПЗ атрибутами й бачить, чи це медвиріб, який у нього клас за MDR, що з
цього випливає за AI Act і які обов'язки потрібні. Кожна відповідь простежується до дослівної цитати офіційного тексту.

> **Демо, не юридична консультація.** Клас визначає виробник; для IIa і вище його підтверджує нотифікований орган.
> Правила — чернетка, не перевірені регуляторним фахівцем.

![Мапа вимог для застосунку, що аналізує серцебиття: клас IIb, розгорнута гілка «шлях на ринок», картка «як виконати» з цитатою; наведення на вимогу підсвічує атрибути, що її спричинили](docs/screens/01-map.png)

Робота триває: див. [docs/SPEC.md](docs/SPEC.md) (етапи M0–M6) і [docs/DECISIONS.md](docs/DECISIONS.md).

## Як запустити

Потрібні Node ≥ 22.18 і pnpm 10.28 (`corepack enable`).

```sh
pnpm i
pnpm verify      # tsc, Biome, усі тести (зокрема кожна цитата й кожен еталонний приклад MDCG)
pnpm dev         # web локально
pnpm build:web   # статична збірка в apps/web/dist (працює з будь-якого підшляху, напр. GitHub Pages)
pnpm e2e         # статична збірка в Chromium (Playwright, передвстановлений браузер)
pnpm mrn help    # CLI: джерела, цитати, перевірки, оцінка профілю, знімок даних
```
